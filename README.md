## Kullanım

Kurmak istediğiniz eklentinin **Releases** bağlantısını açın ve ilgili sürüm için hazırlanmış XenForo kurulum ZIP dosyasını indirin. Kurulum ve sürüme özel gereksinimler için eklentinin kendi README dosyasını kontrol edin.
